GHOSTING DETECTOR — presentación web
====================================

Contenido:
- index.html
- assets/waiting.png
- assets/detector.png

Para probar:
Abrí index.html en un navegador.

Para publicar en inaki.ar/ghosting:
Subí la carpeta completa manteniendo la estructura /assets.

Nota académica:
La demo del índice está explícitamente presentada como una simulación ilustrativa.
El TP propone construir un Índice de Ghosting, pero no define todavía una fórmula validada.
